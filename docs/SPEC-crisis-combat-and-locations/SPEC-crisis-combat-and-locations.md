# Rim Chronicles — Crisis Combat & Locations Spec

**For:** Claude Code · **Owner:** John · **Date:** 2026-11-22 (rev. 5: vanilla psycasts for iteration 1; VPE as a hard dependency in a later iteration)
**Parent spec:** Rim Chronicles — Design Spec (Stages 0–5). Sibling: `SPEC-director-model.md`. Where they disagree, the parent spec wins.

---

## 1. Goal

Make the Awakened Empire a real **endgame crisis**: hard, escalating, and fought the way a skilled player fights. The Empire uses top-tier troops, psykers who actually cast, telegraphed orbital strikes, drop-pod decapitation strikes and sieges that dig in and grow.

Also give the player **places to travel to** (Empire citadels, relays, outposts) that are generated by code from hand-built pieces, not fully hand-made maps.

### Core rule (same as the director spec)

**The LLM picks the strategy, code does the execution.** The director chooses an operation or a site archetype from an allowed list and gives a reason. Code owns units, tactics, placement, threat budget and timing. Gemma answers in 3–10 s, so it never makes tick-level decisions.

### Non-goals (iteration 1)

- LLM-generated map layouts. The model never draws geometry.
- Replacing vanilla raids for other factions. This applies to Awakened Empire forces only.
- Unwinnable content. Hard, but every threat has counterplay (§8).
- Psycast mods. Iteration 1 uses **vanilla Royalty psycasts only**. VPE support is planned for a later iteration (§12); the `IPsycastProvider` interface (§5.3) is there so it can be added without rewriting the psyker AI.

## 3. Piece library

A **piece** is a small hand-built chunk: a room, an emplacement or a defensive line.

### 3.1 PieceDef (XML)

```xml
<RimChronicles.PieceDef>
  <defName>RC_Piece_MortarPit</defName>
  <size>(5,5)</size>
  <tags><li>Emplacement</li><li>Artillery</li></tags>
  <doorSides>South</doorSides>          <!-- where it can connect -->
  <needsPower>false</needsPower>
  <defenseValue>3</defenseValue>
  <threatCost>120</threatCost>         <!-- used by the threat budget -->
  <buildOrder>2</buildOrder>           <!-- for sieges: when it gets built -->
  <layout>                              <!-- char grid + legend -->
    <rows><li>SSSSS</li><li>S...S</li><li>S.M.S</li><li>S...S</li><li>SS.SS</li></rows>
    <legend><S>Sandbags</S><M>Turret_Mortar</M></legend>
  </layout>
</RimChronicles.PieceDef>
```

- Pieces can be rotated in steps of 90°. Door sides rotate with the piece.
- Stuff (materials) is chosen at stamp time from the site or raid's tech and wealth.
- Two ways to stamp: **instant** (location generator spawns things) or **blueprint** (siege planner places blueprints for pawns to build).

### 3.2 Starter set (15–30 pieces)

Rooms: throne room, psychic amplifier chamber, barracks, armory, archotech vault, command room, shuttle pad, gatehouse, prison block, records room (holds intel, §5.6).
Emplacements: mortar pit, sandbag line (straight/corner), turret nest, shield emitter, Herald uplink, psychic relay, drop-pod beacon.

Each piece gets a test that stamps it on an empty map and checks it fits its declared size and doors.

## 4. Location generator

### 4.1 Site archetypes

| Archetype | Size | Objective | Notes |
| --- | --- | --- | --- |
| **Forward Outpost** | Small | Destroy comms or capture officer | Early crisis; teaches the faction |
| **Psychic Relay** | Medium | Destroy relay core | Disabling it weakens Empire psykers for N days |
| **Orbital Uplink** | Medium | Destroy uplink | Disabling it stops orbital strikes for N days |
| **Citadel** | Large, **one map** (§4.5) | Kill or capture the High Stellarch | Endgame finale site |
| **Reclaimed Holding** | Varies | Liberate / hold | Territory the Empire has taken back |

Each archetype is a `SiteArchetypeDef`: required pieces, optional pieces with weights, defender roster, wall/turret density, threat budget range.

### 4.2 Generation steps

1. **Partition** the build area (BSP or similar) into room slots.
2. **Connect** slots with a graph; the objective room is placed deepest from the entry side.
3. **Fill** slots with pieces by tag and size; required pieces first.
4. **Wrap** with walls, gates and outer defenses scaled to the threat budget.
5. **Populate** defenders from the roster.
6. **Validate** (§4.3). On failure, regenerate with the next seed; after 5 failures, fall back to a known-good fixed layout for that archetype and log it.

Everything is seeded from the site's world-object ID, so the same site always generates the same map.

### 4.3 Validators

- **Reachability:** flood-fill from every map edge to the objective; at least one path must exist.
- **Power:** every piece with `needsPower` connects to a generator.
- **No sealed rooms** unless the piece is tagged `Sealed` (vaults with a breach-only entry).
- **Budget:** total `threatCost` of defenses and defenders is within the archetype's range.

### 4.4 Director's role

When a plot creates a site, the allowed list offers archetypes (e.g. `Site:PsychicRelay`, `Site:OrbitalUplink`). The director picks one and returns a reason. A second, optional call fills **flavor only**: site name, one lore line for the news agent, and which optional special room to include (from an allowed list). Code does the rest.

### 4.5 Citadel (decided: one large map)

The Citadel is a single large map (default 275×275, configurable; check performance on John's PC) with the assault layered **inside** the map instead of across maps:

| Ring | Contents | Gate to next ring |
| --- | --- | --- |
| **Outer works** | Trench lines, turret nests, mortar pits, patrols | Breach the outer wall or gatehouse |
| **Courtyard** | Barracks, armory, shuttle pad, Herald uplink, psychic relay | Destroy or capture the relay to drop the keep's psychic shield |
| **Inner keep** | Throne room, records room, archotech vault, High Stellarch + honor guard | Objective |

- Generation runs §4.2 once per ring, outermost first, each inside the previous ring's walls.
- **Defender reaction:** when the player enters a ring, defenders from the next ring inward move up to reinforce. The keep's honor guard never leaves the keep.
- **Psychic shield on the keep:** while the courtyard relay stands, keep walls and doors take heavily reduced damage and Empire psykers inside get a psyfocus bonus. This makes the relay a required objective, not optional.
- **Earlier sites matter:** each Psychic Relay / Orbital Uplink site the player has destroyed removes one courtyard relay or uplink (or weakens it), and intel (§5.6) can reveal the keep's layout or a side entrance.
- Validators run per ring, plus one whole-map reachability check from the edge to the throne room.
- Performance budget: map gen under 30 s; steady 60 TPS at speed 1 with all defenders spawned. If that's missed, spawn courtyard and keep defenders only when the player reaches the ring before them.

## 5. Raid commander

### 5.1 Units (PawnKindDefs)

| Role | Kit | Job |
| --- | --- | --- |
| **Praetorian** | Cataphract armor, charge lance / persona weapon, bionics | Line troops |
| **Psyker Adept** (one kind per specialty, §5.3.1) | Prestige robes, psylink 2–6 by stage, high psychic sensitivity, a fixed set of vanilla psycasts | Psycast support |
| **Herald** | Light armor, orbital targeter | Calls orbital strikes (§5.4); priority target. Not a psyker. |
| **Breacher** | EMP and smoke grenades, breach tools | Knocks out turrets, opens walls |
| **High Stellarch** | Best gear, psylink 6, psycasts from two specialties | Finale commander; boss |

Gear quality and bionics scale with the crisis stage (§6), not with colony wealth alone.

### 5.2 Operations

Each operation is an `OperationDef` with a custom lord job. These are the ids the director picks from.

| Operation | Shape |
| --- | --- |
| `Operation:ProbingRaid` | Small force tests defenses, retreats early, reports back (raises later raids' knowledge of the colony layout) |
| `Operation:SiegeWithBombardment` | Builds a siege camp (§5.5), then bombards |
| `Operation:Decapitation` | Drop pods land on or near the colony leader / protagonist |
| `Operation:PsychicAssault` | Psyker-heavy force with Praetorian escort |
| `Operation:Breach` | Breachers EMP turrets and open walls, main force follows |
| `Operation:Retrieval` | Strike force goes for a captive or defector held by the colony (§5.6): rescue, or kill if rescue fails |
| `Operation:FinalAssault` | Combined arms, led by the High Stellarch; finale only |

Shared tactical behaviour in every operation:
- **Focus fire** on the closest downed-able threat, then on medics.
- **Retreat and regroup** when losses pass a threshold; come back once with reinforcements if the budget allows.
- **Protect key units:** Praetorians escort Heralds and psykers.
- **Carry off their downed** when retreating if safe, so captures aren't free.

### 5.3 Psyker AI (vanilla psycasts)

Psykers get a `RC_PsykerSupport` duty whose think tree runs an ability-scoring job every ~250 ticks before normal combat. Scorers sit behind an `IPsycastProvider` interface; iteration 1 ships one implementation, `VanillaProvider`, which reads a pawn's Royalty psycasts and casts them through the vanilla ability system.

- Each scored psycast has a **scorer** class, listed in `Defs/RC_Scorers/`: returns a utility score and a target, or nothing. Psycasts without a scorer are never cast by Rim Chronicles pawns.
- **Fixed kits, not random:** Empire pawn kinds get exactly the psycasts their specialty lists (§5.3.1), granted at generation. Strip any random psycasts vanilla gives with the psylink level.
- If vanilla AI casts any psycasts on its own, switch that off for pawns with the `RC_PsykerSupport` duty (Harmony patch if needed) so only our scorers decide.
- **Psykers obey neural heat and psyfocus.** No cheating. An overheated psyker is a window for the player.
- **Enemy ban list** (`RC_EnemyAbilityBlocklist`, XML): psycasts Empire pawns must never get. Starts with `Neuroquake`, `ManhunterPulse` and `Flashstorm` (too chaotic or too hard to counter for v1), and `EntropyDump` (colonist-only target; a day-long coma). Non-combat psycasts (`Waterskip`, `SolarPinhole`, the `WordOf*` casts, `Focus`) have no scorer, so they are never cast. Review during balance.
- Every scorer names the psycast defs it needs; at startup, if one is missing, disable that scorer and log a warning. Never throw.

#### 5.3.1 Specialties (vanilla psycasts)

Fixed to the real Royalty defs in the C0 survey (2026-11-22; full list in `docs/ENGINE_NOTES.md`, "Crisis survey"). Names are defNames; the number is the psylink level a psycast needs. A specialty only gets the psycasts its pawn's psylink level allows.

| Specialty (pawn kind) | Psycasts (level) | Battlefield job | Used most in | First stage |
| --- | --- | --- | --- | --- |
| **Skip Adept** | `ChaosSkip` (3), `Beckon` (3), `Skip` (4), `MassChaosSkip` (6) | Pulls colonists out of cover or into Praetorians, scatters defenders | Decapitation, Retrieval, Breach | 1 |
| **Control Adept** | `Stun` (1), `Burden` (1), `BlindingPulse` (2), `VertigoPulse` (3) | Slows and disables defenders, especially shooters | PsychicAssault, Siege | 1 |
| **Mind Adept** | `Berserk` (5), `BerserkPulse` (6) | Turns clustered colonists on each other | PsychicAssault | 3 (needs psylink 5) |
| **Ward Adept** | `Painblock` (1), `Chunkskip` (1), `Smokepop` (4), `Wallraise` (4), `Invisibility` (5), `BulletShield` (6) | Keeps Praetorians standing, blocks lines of fire, hides flankers | All operations | 1 |
| **High Stellarch** | Skip + Ward kits, plus `Farskip` (5) to escape once at low health | Commands the honor guard, rescues itself once | Citadel, FinalAssault | 4 |

Survey corrections: vanilla has **no Mass Burden** (dropped; Vertigo and Blinding Pulse are the Control Adept's area casts). **Chunkskip** is added to the Ward kit so low-level Ward Adepts have more than Painblock (it drops rock chunks as cover). **Entropy Dump** exists but targets only colonists and puts its target in a coma for a day, so it joins the ban list (§5.3). **Farskip** is a world-map cast built for player caravans; the Stellarch's escape uses its psyfocus cost and visuals with a scripted exit (C13).

Starting scorers (one or two per specialty):
- **Skip:** skip the colonist in the best cover (or with the best weapon) out into open ground or next to 2+ Praetorians; skip an ally out of a losing melee.
- **Chaos / Mass Chaos Skip:** 3+ colonists holding a chokepoint or killbox.
- **Beckon:** pull a colonist who is shooting from cover toward Praetorians.
- **Stun:** the colonist with the highest-damage weapon in range.
- **Burden:** a colonist closing on a psyker or Herald.
- **Vertigo / Blinding Pulse:** 3+ colonists in radius, few allies in radius.
- **Berserk:** a colonist standing in a group of 2+ other colonists; **Berserk Pulse:** 3+ colonists in radius, few allies.
- **Painblock:** the most valuable ally that is in pain and still fighting.
- **Chunkskip:** cover for allies pinned in the open; **Wallraise:** block the doorway or gap the colony's turrets are firing through; **Smokepop:** cover an advance across open ground.
- **BulletShield:** a group of 3+ allies under ranged fire.
- **Invisibility:** a flanking adept or the Herald when it has no line of sight yet.
- **Shared:** hold (no cast, keep fighting) when heat is high or psyfocus is low and nothing scores well.

**Operation mix:** each `OperationDef` lists which specialties it draws and in what ratio (e.g. PsychicAssault: Mind 2, Control 2, Ward 1 per 6 Praetorians), scaled by stage.

### 5.4 Orbital strikes

- Uses Royalty's bombardment / power beam things, spawned from code.
- **Always telegraphed:** the Herald paints a target, which shows a targeting laser and a letter. Delay before impact: 6–10 s game-time (tune in testing).
- **Has a source:** strikes only happen while a Herald is alive, conscious and in line of sight of the target, or while an Orbital Uplink site / siege uplink piece is standing.
- **Cooldown** between strikes; a cap per raid set by the threat budget.
- Never targets the same cell twice in a row; prefers turrets, clustered colonists and power infrastructure.

### 5.5 Siege planner

Replaces the vanilla siege blueprint placer for Empire sieges.

**Choose the camp spot.** Sample candidate spots around the colony and score them on:
- distance (outside turret and mortar range of the colony, inside the Empire's own mortar range);
- cover and terrain between camp and colony;
- line toward the colony's main entrances (from the probing raid, if one happened);
- not on a cell the player can easily flank on both sides.

**Build in stages** (pieces by `buildOrder`, stamped as blueprints):

| Stage | Pieces | Unlocks |
| --- | --- | --- |
| 1 | Sandbag lines, tents | Camp exists |
| 2 | Mortar pits | Bombardment |
| 3 | Herald uplink | Orbital strikes |
| 4 | Shield emitter / psychic relay | Psyker buffs, projectile protection |
| 5 | Drop-pod beacon | Reinforcement waves |

Each stage only starts when the one before is built. This is the player's decision point: strike early while the camp is weak, or wait and face more.

**Siege goal.** The director may also pick the siege goal from an allowed list: `Goal:BreakWalls`, `Goal:Starve` (target farms, freezers, power), `Goal:KillLeader`. The goal changes strike targeting, not the camp.

If the camp loses most of its builders, the siege turns into a direct assault or retreats, depending on what's left of the budget.

### 5.6 Captives, interrogation and defectors (decided: feeds the plot)

Captured Empire troops are a source of **intel** and of **new plot threads**.

**Captives**
- Empire pawns arrive with very high resistance and will (Imperial loyalty). Rank sets how high and what they know.
- New prisoner mode **Interrogate**, next to vanilla's recruit/convert/enslave modes. A warden with good Social works on it; each success yields one **intel item**. Captives can also be recruited once resistance is broken, but interrogating first lowers loyalty faster.
- Captured psykers keep their psylink and psycasts. A recruited one is a real asset, which is part of why the Empire comes for them (`Operation:Retrieval`).

**Intel items** (`IntelDef`, stored in a colony intel log the news agent can mention)

| Source rank | Intel | Effect |
| --- | --- | --- |
| Praetorian | Patrol routes / garrison size | Reveals the defender count of one known site |
| Breacher | Next operation | Warns of the next operation's type and rough timing |
| Herald | Uplink codes | Next raid's Herald strikes are delayed or fail once; or reveals an Orbital Uplink site |
| Psyker Adept | Relay location | Reveals a Psychic Relay site; next psychic assault has fewer adepts |
| Officer / Stellarch's aide | Citadel plans | Reveals the keep's layout or a side entrance (§4.5) |

Intel can also be found in the **records room** piece at sites. Every intel item has an expiry where that makes sense (operation warnings go stale).

**Defectors**
- A captive recruited after interrogation becomes a **defector**: a colonist with Empire backstory and possibly psylink.
- A defector can become the **protagonist of a minor plot** (the director's normal minor-plot rules apply, including passing the plot on when they die).
- The Empire reacts: `Operation:Retrieval` becomes allowed while a captive or defector is held, and the news agent can report the defection.

**How the player treats captives matters.** Executing, harvesting or enslaving Empire captives is written to the world summary as tales; the director sees them and can choose harsher responses (e.g. an Imperial vengeance complication). Releasing a captive can earn a small goodwill or a one-time reduced operation. Code applies the effects; the director only picks from allowed options.

**Director integration:** captives, defectors and intel items appear in the world summary. New ids: `Operation:Retrieval`, `Complication:DefectorHunted`, `Complication:ImperialVengeance`, `Hook:DefectorPlot`, filtered by what the colony actually holds.

## 6. Threat budget and escalation

The crisis has **its own threat budget**, separate from the storyteller's raid points (code owns threat points, per the parent spec).

- `budget = base(stage) × difficulty × clamp(colonyStrength, min, max)`
  - `colonyStrength` blends combat-pawn power, armor/weapon quality and defenses. Wealth counts for less than in vanilla so the crisis can't be dodged by staying poor.
  - Colonists' own psylink levels count toward `colonyStrength`.
- **Crisis stages** follow the Empire plot state:

| Stage | Plot state | Operations allowed | Unit quality | Adept psylink |
| --- | --- | --- | --- | --- |
| 1 Stirring | Empire awakening | ProbingRaid | Good | 3 |
| 2 Reclamation | Taking territory | + Breach, PsychicAssault, Retrieval | Excellent | 3–4 |
| 3 War | Open war | + SiegeWithBombardment, Decapitation | Masterwork | 4–5 |
| 4 Finale | Endgame | + FinalAssault | Legendary on leaders | 5–6 |

Adept psylink is set by the C0 survey: stage 1 is 3, not 2–3, because Skip Adepts need level 3 for their first cast. Level 3–4 psycasts need 25% psyfocus and level 5–6 need 50% (vanilla psyfocus bands), so high-level casts stop as a psyker's psyfocus runs down.

- Destroying a Psychic Relay or Orbital Uplink site **removes** that capability for N days and weakens the Citadel (§4.5). Player actions at locations feed back into raids; that's the link between the two modules.
- Intel (§5.6) can reduce or delay operations; it never removes the crisis.
- Minimum gap between crisis operations (pacing gate, same idea as the director's).

## 7. Director integration

Nothing about the director's contract changes. New transition ids appear in the allowed lists:

- **Operations:** `Operation:*` from §5.2, filtered by stage, budget, cooldowns and (for Retrieval) whether the colony holds a captive or defector.
- **Siege goals:** `Goal:*`, only when the chosen operation is a siege.

Fallback is unchanged: invalid or failed call → weighted random among allowed options.

## 8. Fairness rules

These are hard rules; tests check them.

1. Every orbital strike is telegraphed and needs a living Herald or a standing uplink.
2. Psykers obey neural heat and psyfocus.
3. Drop pods never land inside a fully roofed room with overhead mountain.
4. Every site passes the reachability validator; the Citadel passes it per ring and edge-to-throne.
5. Every siege camp is built in stages the player can interrupt.
6. Every operation can retreat; no raid fights to the last pawn except the FinalAssault.
7. The news agent announces stage changes, so the player sees escalation coming.
8. The Citadel's keep shield always has a reachable relay that turns it off.
9. No Empire pawn ever has or casts a psycast on the enemy ban list (§5.3).

## 9. Testing and dev tools

- **Dev Mode actions:**
  - "RC: Generate site" — pick archetype + seed, generate, view.
  - "RC: Batch sites" — generate 50 seeds, log validator results and piece usage.
  - "RC: Fire operation" — pick operation + stage, spawn on the current map.
  - "RC: Show siege scoring" — overlay candidate camp spots with scores.
  - "RC: Psyker debug" — draw each psyker's top scorer, target, heat and psyfocus.
  - "RC: Spawn adept" — pick specialty + stage, spawn hostile; "RC: Check psycasts" — list every scorer and whether its psycast defs were found.
  - "RC: Spawn captive" — pick rank, spawn as prisoner; "RC: Grant intel" — pick intel item.
- **Unit tests:** piece stamping, rotation, validators, budget math, scorer logic on fixed fixtures, intel effects, ban list enforcement.
- **Psyker tests:** every specialty spawns with exactly its kit and no banned psycasts; every scorer's psycasts resolve; each specialty casts at least once in a scripted fight; no RC pawn casts a psycast its scorers didn't choose.
- **Playtest bar:** with a well-defended late-game test colony at default difficulty, Stage 3 operations should cause real losses but be winnable without save-scumming; Stage 4 and the Citadel should need preparation (taking out relay/uplink sites and gathering intel first).

## 12. Later iteration: Vanilla Psycasts Expanded (iteration 2 or 3)

Kept here so the design isn't lost. Not built in iteration 1.

**Why:** VPE gives far richer psycast trees and many players already run it, so Empire psykers could have proper specialties.

**How it plugs in:**
- Add `VpeProvider` as a second `IPsycastProvider`. **VPE and Vanilla Expanded Framework become hard dependencies** in that iteration (decided, §11); Rim Chronicles loads after them.
- Startup check logs VPE/VEF versions and disables scorers whose abilities are missing. Record tested versions in `docs/tested-versions.md`; each RimWorld update, wait for VPE/VEF, rerun the VPE tests, bump the file.
- RC pawns opt out of VPE's own enemy-casting AI and its random NPC psycaster generation (Harmony patch if needed); kits stay fixed.
- Extend the ban list for VPE: resurrection, instant-kill and long-range assassination abilities.
- Survey VPE's source first (`docs/vpe-api-notes.md`): path and ability defNames, NPC generation, enemy AI, casting from code.

**Draft specialty mapping** (working names; confirm against VPE):

| Specialty | VPE path(s) | Job |
| --- | --- | --- |
| Warlord Adept | Warlord | Buffs and fights beside Praetorians |
| Skip Adept | Skipmaster | Repositions allies, pulls colonists out of cover |
| Storm Adept | Staticlord | Lightning/EMP on turrets and batteries |
| Frost Adept | Frostshaper | Slows and freezes defenders |
| Ward Adept | Protector | Shields and heals allies |
| Mind Adept | Empath (or nearest mental-effects path) | Berserk, confusion, mood attacks |
| High Stellarch | Warlord + Skipmaster | Commands, skips to threats, rallies troops |

Add VPE regression tests (spawn kits, abilities resolve, each specialty casts, VPE AI never casts for RC pawns) and rerun them on every VPE update.
